# Documentação e retrospectiva

Documentar o estado final, a partir de artefatos e trechos pertinentes; sem reabrir toda investigação. Distinguir decisões deliberadas de dúvidas. Tamanho proporcional à tarefa.

Retrospectiva usa runs e associação de sessões. Sem vínculo, custo/espera/rework ficam desconhecidos. Não inferir culpa do dono pela data dos arquivos nem atribuir todo finding a falha de plano. Publicação no BookStack é ação explícita via ferramenta existente, fora do runner v2.
